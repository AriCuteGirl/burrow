# Changelog

## Unreleased
- Settings ▸ Colours: follow the active rice, or always use one installed rice's look
- Installer: `xdg-open` now finds Burrow as the default for folders

## 0.4.0 (2026-11-22)
- Thumbnails for images, videos, PDFs, fonts and more, in the shared XDG cache; external tools run sandboxed
- Preview pane (F4) and quick look (Space)
- Search in subfolders, with `*` and `?`
- Every shortcut can be changed; optional vim keys
- Custom right-click actions
- Faster big folders, which now open at the top

## 0.3.0 (2026-11-22)
- Network page, Connect to server, logins with the system keyring, phones
- Share a folder on the LAN through Samba user shares

## 0.2.0 (2026-11-21)
- Copy, move, paste, drag and drop with a clash dialog, progress, pause, cancel and undo
- Trash with restore, batch rename, archives, shortcuts, New ▸, Open with, Properties

## 0.1.0 (2026-11-21)
- Browsing in grid, compact and list views, tabs and split view
- Sidebar with your own sections, favorites and drives with usage bars
- Follows the active hypr-rice live; settings window and config.toml stay in sync
